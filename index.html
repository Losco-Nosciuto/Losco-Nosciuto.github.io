Method

A few rules, always kept.

Pipeline first

If the flow is clear, the result is repeatable. I automate what repeats and keep human judgment where it really matters.

Reference before render

Photos, floor plans, real videos: documentation decides the quality long before the first polygon or the first cut.

Document as you go

Consistent notes, versions and names. It helps me in six months, and it helps anyone who has to pick the project up again.
