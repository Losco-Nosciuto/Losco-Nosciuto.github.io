MSFS 2024 · Blender · commercial · v4

LN LODs Pro

A Blender add-on that calculates LOD thresholds from the MSFS 2024 exporter's own vertex count, so the number you see in Blender is the number the simulator will use. A viewer tests the transitions before export; the exporter remains the only pipeline.

Started in 2023 and developed in phases, it is now in rework and integration into a suite of MSFS tools. The free base stays free; the Pro modules add the viewer and testing mode. Until the suite ships, the name stays LN LODs Pro.

MSFS 2024 OpenCode Workspace

Six OpenCode agents and a verified MSFS 2024 knowledge cache: a cache-first research pipeline, a read-only planner for Blender add-ons and MSFS tools, parallel research sub-agents, a single writer and validation gates. It is the workflow behind the LN LODs Pro suite.

Agents
Six: cache updater, planner, dump triage, research, cache writer, source scout.
Cache
Status-labelled facts with sources: cited, empirical, inferred, unknown.
Tooling
